# قائمة التحقق على ويندوز: المرحلة 2 (لوحة "جهازي")

شرط انتهاء المرحلة: كل رقم يظهر في اللوحة يطابق تقريباً مصدراً ثانياً، وكل قراءة غير متوفرة تظهر "غير متاح" بدل رقم مخترع.

## 0. التحديث

```powershell
cd $HOME\blazma-ai
git pull
npm install
npm start
```

انتظر حتى تصبح المحادثة "جاهز"، ثم افتح صفحة **جهازي**. افتح Task Manager بجانبها (Ctrl+Shift+Esc، ثم Performance).

## 1. مطابقة الأرقام

قارن كل قيمة مع مصدرها. الفرق البسيط طبيعي، لأن القراءات لا تُؤخذ في نفس اللحظة.

| في التطبيق | قارن مع |
|---|---|
| كرت الشاشة: الاستخدام، ذاكرة الكرت، الطاقة، الحرارة، المروحة، السرعة، حالة الأداء | في PowerShell ثانٍ: `nvidia-smi` |
| ذاكرة الكرت للموديل | Task Manager، ثم Details، ثم عمود "Dedicated GPU memory" لـ`llama-server.exe` (أضف العمود بالزر الأيمن على رأس الجدول) |
| المعالج: الاستخدام | Task Manager، ثم Performance، ثم CPU، ثم Utilization |
| المعالج: السرعة الحالية | Task Manager، ثم CPU، ثم Speed |
| الأنوية / الخيوط | Task Manager، ثم CPU: Cores / Logical processors |
| الذاكرة: المستخدم والمتاح | Task Manager، ثم Memory: In use / Available |
| نوع الذاكرة وسرعتها | Task Manager، ثم Memory: Speed، و"Form factor" |
| ذاكرة الجهاز للمحرك | Task Manager، ثم Details، ثم Memory لـ`llama-server.exe` |
| المساحة الفاضية | This PC، والقرص الذي فيه مجلد المستخدم |

- [ ] كل الأرقام متطابقة تقريباً. سجّل أي رقم مختلف مع صورة.
- [ ] حرارة المعالج وطاقته تظهر "غير متاح" مع السبب.
- [ ] الرسوم البيانية تتحرك، وتتوقف عندما تنتقل لصفحة ثانية أو تصغّر النافذة.

## 2. التنبيهات

1. من **الإعدادات**، ثم لوحة "جهازي": ألغِ "تلقائي"، وضع التحذير 40 والخطر 50، ثم احفظ.
2. ارجع للمحادثة واطلب مقالاً طويلاً لتسخين الكرت.

- [ ] يظهر شريط أصفر ثم أحمر أعلى الصفحة بالعربي.
- [ ] صغّر النافذة أثناء التوليد. هل ظهر إشعار ويندوز؟
- [ ] أرجع "تلقائي" واحفظ. ما القيم التلقائية المكتوبة؟ (المتوقع لـRTX 5070: خطر 85، وهو الحد الرسمي من NVIDIA.)

## 3. اختبار الأداء والتقرير

- [ ] اضغط "اختبار أداء". تظهر سرعة التوليد وسرعة معالجة الإدخال وأقصى حرارة وأقصى طاقة.
- [ ] اضغط "تصدير تقرير الجهاز" واحفظ الملف. افتحه وتأكد أنه **لا يحتوي** اسم المستخدم ولا اسم الجهاز.

## 4. التشخيص

```powershell
npm run diag
```

- [ ] أرسل `diag-report.txt`. فيه الآن قراءات ويندوز التي تعتمد عليها اللوحة.
